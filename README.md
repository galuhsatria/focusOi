# FocusOI - Chrome Extension for Pomodoro

**FocusOI** is a simple and effective Chrome extension designed to help you stay focused and productive using the **Pomodoro Technique**. It allows you to manage your work and break intervals with ease—perfect for studying, working, or deep focus sessions.

## ✨ Features

- ⏲️ Easy-to-use Pomodoro timer
- 🕒 Custom time 
- 🔔 Notifications when sessions end

## 📥 Installation

1. Clone or download this repository:
   
   ```bash
   git clone https://github.com/username/focusoi.git
   ```
   
3. Open Google Chrome and go to chrome://extensions/.
4. Enable Developer Mode in the top right corner.
5. Click Load unpacked and select the folder where you cloned the project.

The FocusOI extension is now ready to use!
